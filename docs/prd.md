# 产品需求文档 (PRD): Maven Skill

## 1. 背景与目标

### 1.1 业务背景
课程运营者需要查看 Maven（maven.com）的课程、班期和学员报名情况，并下载报表 CSV。本项目用浏览器观察与导航支持这些任务，减少对内部 API 的绑定。官方 API 的可用范围尚未核实。

### 1.2 核心目标
1. **建立安全可靠的会话连接底座**：借助 Playwright 驱动真实的系统级 Google Chrome，由人类完成初始登录，并将认证凭据持久化保存在独立 Profile 中。
2. **提供标准化的 CDP 通信接口**：使 AI Agent 能够通过 Chrome DevTools Protocol (CDP) 接入运行中的浏览器，执行低侵入式的页面观察与导航。
3. **输出结构化数据**：所有 CLI 命令均输出标准 JSON 格式，方便 Agent 解析与状态判定。
4. **确立只读与安全红线**：严格遵循最小特权原则，仅用于只读观察和报表获取，杜绝非授权的数据修改。

### 1.3 非目标（当前阶段）
- **不逆向私有 API**：不对 Maven 的私有 HTTP 接口进行脆弱的逆向绑定。
- **不提前编造选择器**：在未接入真实实机环境验证之前，不预设任何具体的 DOM 选择器或页面元素路径。
- **不支持自动绕过登录**：不尝试通过算法自动化破解多因素验证或验证码，登录过程交由人类用户在图形窗口完成。
- **不提供未经测试的快照恢复命令**：尽管支持导出认证状态 JSON，但在未经完整跨浏览器实机测试前，不提供基于该 JSON 的自动登录恢复命令。

## 2. 用户角色与典型流程

### 2.1 角色定义
- **人类操作者**：负责初次运行命令、在弹出的 Chrome 窗口中完成账号登录、必要时提供授权。
- **AI Agent**：负责在人类完成登录后，通过 CLI 连接 CDP 端口，观察页面内容，执行必要的只读导航与数据汇总。

### 2.2 核心工作流程
```
[人类操作者]
   │
   ├─► 1. 运行: maven-skill session open
   │      └─► 弹出独立 Chrome 窗口
   │
   ├─► 2. 人工在窗口中登录 Maven 账号 (Google / Email)
   │      └─► 登录态写入 .local/browser-profile
   ▼
[AI Agent]
   │
   ├─► 3. 运行: maven-skill session status
   │      └─► 确认 CDP 端口可连通
   │
   ├─► 4. 运行: maven-skill page snapshot
   │      └─► 读取当前页面结构化文本，判断所在页面
   │
   ├─► 5. 运行: maven-skill page goto <URL>
   │      └─► 导航至目标管理页面
   │
   └─► 6. [后续目标] 观察 Cohort 列表与触发报表 CSV 下载
```

## 3. 功能需求规格

### 3.1 会话管理 (Session Management)
- **`session open`**：
  - 参数：可选 `--url`（默认为 `https://maven.com/`）。
  - 行为：启动一个绑定到独立 Profile 目录（默认 `.local/browser-profile`）的 Chrome 实例，开启 CDP 远程调试端口（默认 `9337`）。
  - 若指定端口已有会话运行，直接复用连接，且**严禁覆盖或重载用户当前停留在该会话上的页面**。
- **`session status`**：
  - 行为：向 CDP 调试端口发送探测请求。
  - 语义定义：返回连接状态 JSON。仅用于表明调试端口是否活跃可连，**不代表 Maven 平台处于已登录状态**。
- **`session save`**：
  - 行为：从当前活跃浏览器上下文中提取 Cookies、localStorage 以及 IndexedDB，保存为 `.local/auth-state.json`。
  - 注意事项：不包含 `sessionStorage`。文件权限必须限制为 `0600`。
- **`session close`**：
  - 行为：首先自动执行一次 `session save` 保存最新认证状态，随后优雅终止对应的 Chrome 进程。

### 3.2 页面交互 (Page Interaction)
- **`page snapshot`**：
  - 行为：连接当前浏览器活跃页面，获取当前视口与 DOM 中的可见文本与主要结构，输出 JSON。
  - 隐私保护：快照中可能包含敏感学员名单或商业指标，仅限本地分析使用。
- **`page goto <URL>`**：
  - 行为：在当前已打开的活跃页面上执行导航跳转。

### 3.3 全局参数与环境配置
- 全局选项：
  - `--data-dir`：指定运行时数据存储目录，默认值为 `.local`。
  - `--port`：指定 CDP 调试端口，默认值为 `9337`。
- 环境变量支持：
  - `MAVEN_DATA_DIR`：覆盖默认数据目录。
  - `MAVEN_CDP_PORT`：覆盖默认调试端口。
  - `MAVEN_CHROME_EXECUTABLE`：可选指定系统 Chrome 可执行文件路径。
- 配置文件说明：CLI 工具不会自动读取 `.env` 文件，必须由外层 shell 环境显式注入。

## 4. 安全与合规要求

1. **网络隔离**：CDP 调试端口拥有完全的浏览器控制权限，必须且仅能绑定到本地回环地址（`127.0.0.1` / `localhost`），禁止监听外网接口。
2. **文件系统隔离与权限**：
   - 目录权限控制：`.local` 及子目录在创建时必须设置权限为 `0700`。
   - 文件权限控制：导出的认证状态文件权限必须为 `0600`。
   - 忽略规则：`.local/`、临时下载文件、日志文件、`.env` 严禁提交至版本控制系统。
3. **只读保护与权限升级**：
   - 严禁擅自修改课程设置、排期、学生状态或发表言论。
   - 严禁调用任何形式的邀请发送、批量邮件或记账操作。
   - 任何破坏性写入操作均需独立的显式授权。
